# Predicting MLB Game Outcomes After Six Innings

## By: Ruby Collins and Nick Degnan

### Background

In baseball, a quality start is a statistic that occurs when the starting pitcher pitches at least six innings while allowing three or fewer runs. This type of start puts the team in a competitive position entering the final stretch of the game by keeping the opponent’s score low. This project will explore other metrics, offensively and defensively, that set teams up for success after the first six innings of a game. Using these insights, we’ll create a model to predict the outcome of games after six innings. We will compare this to a score-based model to see if underlying statistics provide more predictive value than score alone.

### Working Research Question

Do underlying in-game statistics provide more predictive value than score alone does in predicting the outcomes of MLB games after six innings?

### Hypothesis

In-game and underlying team statistics will provide more predictive value than the game score alone in predicting the outcomes of MLB games after six innings.

### Predictions

Statistics beyond the score will be especially valuable in predicting game outcomes in circumstances where there is not a drastic score difference between teams. For example, if a game is 10-0 after six innings, the underlying statistics likely would not add value to outcome prediction because winning outcome is already very high based on score alone. However, if a game is tied, statistics beyond score will be needed to assess and predict the outcome. Statistics like quality starts, on base percentage, and late inning averages could be influential in the predictive model.
